# Sudoku Solver 🧩

A Python-based Sudoku game that validates player moves according to standard Sudoku rules.

## ✨ Features

- Validates numbers based on row, column, and 3×3 box rules.
- Checks whether each move is valid.
- Provides interactive Sudoku gameplay.
- Handles the game state and board logic.

## 🛠️ Technologies

- Python
